# CSS — Responsive Web Design

This directory contains my CSS learning archive from the FreeCodeCamp Responsive Web Design curriculum.

The goal of this section is to document the CSS concepts, workshops, labs, and certification projects I completed while learning how to build responsive, accessible, and well-structured web pages.

---

## 📚 Curriculum Structure

The CSS section is organized into four main categories:

- `notes/`
- `workshops/`
- `labs/`
- `certification-projects/`

### Notes

The `notes/` directory contains my personal notes for the CSS concepts covered throughout the curriculum.

These notes focus on understanding the purpose, syntax, and practical usage of CSS features.

### Workshops

The `workshops/` directories contain guided exercises from FreeCodeCamp.

These exercises were completed to practice individual CSS concepts step by step.

### Labs

The `labs/` directories contain practical exercises that combine multiple CSS concepts into small projects and layouts.

### Certification Projects

The `certification-projects/` directory contains the projects completed for the FreeCodeCamp Responsive Web Design Certification.

These projects combine the concepts learned throughout the curriculum and are designed to satisfy specific project requirements and automated tests.

## 🎨 CSS Topics

The CSS section covers the following topics:

### Basic CSS

Fundamental CSS syntax, selectors, properties, values, and styling techniques.

### Absolute and Relative Units

Working with different CSS units such as:

- `px`
- `%`
- `em`
- `rem`
- `vw`
- `vh`

### Pseudo-Classes and Pseudo-Elements

Using pseudo-classes and pseudo-elements to style elements based on their state, position, or relationship with other elements.

Examples include:

- `:hover`
- `:focus`
- `:first-child`
- `::before`
- `::after`

### Colors

Working with different color formats and applying colors to elements.

Examples include:

- Named colors
- Hexadecimal colors
- RGB
- HSL
- Gradients

### Styling Forms

Styling form elements such as:

- Inputs
- Labels
- Buttons
- Checkboxes
- Radio buttons
- Select elements

### The Box Model

Understanding the relationship between:

- Content
- Padding
- Border
- Margin

and how the CSS box model affects element dimensions and layout.

### Flexbox

Using CSS Flexbox to create flexible one-dimensional layouts.

Important concepts include:

- `display: flex`
- `flex-direction`
- `justify-content`
- `align-items`
- `align-self`
- `flex-wrap`
- `gap`
- Flex containers
- Flex items

### Typography

Working with:

- Font families
- Font sizes
- Font weights
- Line heights
- Text alignment
- Text spacing
- Web fonts

### Accessibility

Using CSS together with semantic HTML to create interfaces that are easier to use, navigate, and understand.

### Positioning

Understanding different CSS positioning methods:

- `static`
- `relative`
- `absolute`
- `fixed`
- `sticky`

### Attribute Selectors

Selecting elements based on their HTML attributes and attribute values.

Examples include:

```css
input[type="text"] {
  ...
}
