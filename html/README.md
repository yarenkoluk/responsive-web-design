# HTML

This section contains my HTML learning journey through the freeCodeCamp Responsive Web Design curriculum.

The goal of this section is to document the practical HTML concepts I learned through workshops and labs and to keep the completed exercises organized in a structured project.

## Topics Covered

### Basic HTML

* HTML document structure
* Headings and paragraphs
* Links and images
* Lists
* Classes and IDs
* `div` and `span`
* Figures and captions
* Audio and video
* Iframes
* SVG
* HTML debugging

### Semantic HTML

* Semantic page structure
* `header`
* `nav`
* `main`
* `section`
* `article`
* `footer`
* Description lists
* Quotations and citations
* `figure` and `figcaption`
* `address`

### Forms and Tables

* HTML forms
* Labels and form controls
* Text, email, and number inputs
* Radio buttons
* Checkboxes
* Select menus
* Textareas
* Buttons
* Fieldsets and legends
* Form validation attributes
* Tables
* Table captions
* Table headers and data cells
* `thead`, `tbody`, and `tfoot`
* `colspan`
* Table accessibility with `scope`

### Accessibility

* Semantic HTML for accessibility
* Accessible forms
* Accessible tables
* Alternative text for images
* ARIA attributes
* `aria-label`
* `aria-labelledby`
* `aria-describedby`
* `aria-hidden`
* Accessible audio and video
* Video subtitles and transcripts
* Accessible multimedia content
